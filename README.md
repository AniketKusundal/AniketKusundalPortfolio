## ⚡ Standout Interactive Features

### 1. Interactive Developer Shell Terminal (`ANIKET.SH`)
- Located directly in Chapter 01 (Hero).
- Supports interactive typing and 1-click quick suggestion tags:
  - `skills` ➔ Prints verified core technologies and libraries.
  - `experience` ➔ Displays roles at DigiSevaks Media Agency and Sandhya Softtech.
  - `projects` ➔ Displays WanderAI and ResuMatch AI with jump links.
  - `resume` ➔ Instantly downloads `Aniket_Govind_Kusundal.pdf` with toast confirmation.
  - `sudo hire` ➔ Displays: `"Access Granted: Let's build together!"` and opens WhatsApp.
  - `clear` ➔ Resets terminal output.

### 2. Real Code & Architecture Pipeline Visualizer
Inside each flagship case study, visitors can switch between 3 real-time interactive tabs:
- **`[UI]`**: High-fidelity product interface preview.
- **`[Pipeline]`**: Interactive step-by-step system architecture flow.
- **`[Code]`**: Production-grade Node.js/Express backend snippets (Gemini AI API prompt generation, Tesseract.js OCR parser, Multer stream handling) with 1-click **Copy Code** button.

### 3. Interactive Project Scope Configurator
A boutique project calculator for freelance & agency clients:
- Select project type: *Full-Stack App*, *React.js Website*, *Landing Page*, *WordPress*.
- Multi-select features: *Auth & JWT*, *REST APIs*, *Database*, *Mobile UI*, *SEO*, *AI Integration*.
- Choose target timeline: *Fast Delivery (< 2 Wks)*, *1 Month Standard*, *Flexible*.
- Live outputs:
  - Formatted `PROJECT_BRIEF.SPEC` preview.
  - 1-Click direct dispatch to WhatsApp with pre-filled scope.
  - 1-Click auto-fill into the direct contact form.

### 4. Command Palette (`Ctrl + K` / `⌘K`)
- Global Raycast/VS-Code style spotlight search.
- Instant jump to any case study, experience milestone, tech category, or external profile.

### 5. Reading Line & Live Pune Telemetry
- **Reading Line**: 2px warm orange (`#E8734A`) progress thread anchored right beneath the navbar tracking depth from 0% to 100%.
- **Live Status Badge**: Digital clock synced to `Asia/Kolkata` IST (UTC+5:30) with dual-layer pulsing emerald radar indicator.

## 🛠️ Flagship Case Studies

### ✈️ [WanderAI — AI-Powered Travel Planner](https://github.com/AniketKusundal/Travel-Planner-App-AI-Itinerary-Generator)
- **Problem**: Fragmented itinerary planning and unstructured flight/ticket booking documents.
- **Solution**: Full-stack MERN web app with Google Gemini AI for customized day-by-day itineraries and Tesseract.js OCR for ticket parsing.
- **Stack**: React.js, Node.js, Express.js, MongoDB Atlas, Google Gemini API, Tesseract.js, JWT, Tailwind CSS.

### 📄 [ResuMatch AI — AI-Powered Resume Analyzer](https://github.com/AniketKusundal/AI-Resume-Analyzer)
- **Problem**: Lack of transparency in Applicant Tracking Systems (ATS) and keyword screening.
- **Solution**: Automated in-memory PDF parsing pipeline matching candidate resumes against target Job Descriptions with algorithmic scoring.
- **Stack**: React.js, Node.js, Express.js, MongoDB, Google Gemini 1.5 Pro, Multer (memory stream), pdf-parse, Tailwind CSS.

## 🚀 Quick Start Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# 1. Clone repository
git clone https://github.com/AniketKusundal/AniketKusundalPortfolio.git

# 2. Enter project folder
cd AniketKusundalPortfolio

# 3. Install dependencies
npm install

# 4. Launch local dev server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build
```bash
npm run build
npm run preview
```
